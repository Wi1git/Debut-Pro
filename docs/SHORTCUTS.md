# Debut Pro keyboard shortcuts

Debut Pro uses Premiere Pro-style default shortcuts. On a Mac, **Ctrl means ⌘ Cmd**
and **Alt means ⌥ Option**. You can change any shortcut in Settings → Keyboard Shortcuts.

## Playback and navigation

| Action | Key |
|---|---|
| Play / pause | Space |
| Shuttle backward / pause / forward | J / K / L |
| Step 1 frame back / forward | Left / Right |
| Step 5 frames back / forward | Shift+Left / Shift+Right |
| Previous / next edit point | Up / Down |
| Go to start / end | Home / End |
| Mark In / Out (Source monitor); trim clip start / end to playhead (Timeline) | I / O |
| Go to In / Out | Shift+I / Shift+O |
| Clear In and Out (Source monitor) | Ctrl+Shift+X |

## Editing

| Action | Key |
|---|---|
| Add Edit (split clip at playhead) | Ctrl+K |
| Add Edit to all tracks | Ctrl+Shift+K |
| Ripple trim clip start to playhead | Q |
| Ripple trim clip end to playhead | W |
| Lift (delete, leave a gap) | Delete / Backspace |
| Ripple delete (close the gap) | Shift+Delete, or Alt+Backspace (Mac: ⌥ Delete) |
| Cut / copy / paste clips | Ctrl+X / Ctrl+C / Ctrl+V |
| Paste effects (copied in Effect Controls) | Ctrl+Alt+V |
| Group / ungroup | Ctrl+G / Ctrl+Shift+G |
| Default video transition (cross dissolve, 1 s) | Ctrl+D |
| Default audio crossfade (audio tracks) | Ctrl+Shift+D |
| Undo / redo | Ctrl+Z / Ctrl+Shift+Z or Ctrl+Y |

## Tools and timeline

| Action | Key |
|---|---|
| Selection tool | V |
| Razor tool (click a clip to cut; Shift+click cuts all tracks) | C |
| Ripple mode on/off | B |
| Snapping on/off | S |
| Add marker | M |
| Next / previous marker | Shift+M / Ctrl+Shift+M |
| Zoom timeline in / out | = / - |
| Zoom to fit | \ |

## Project and export

| Action | Key |
|---|---|
| New / save / save as | Ctrl+N / Ctrl+S / Ctrl+Shift+S |
| Import media | Ctrl+I |
| Export panel | Ctrl+M |

## Moved Shotcut shortcuts

If you know Shotcut, these moved to make room: Split is now Ctrl+K (was S),
Add Video Track Ctrl+Shift+I (was Ctrl+I), Select None Ctrl+Shift+A (was Ctrl+D),
Overwrite Ctrl+B (was B), Delete Marker Alt+Shift+M, Loop Ctrl+Shift+L (was \),
Current track up/down Shift+Up/Down, Mute track Ctrl+Alt+Shift+M (Mac: Control+M).
